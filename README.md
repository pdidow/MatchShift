# MatchShift

**Football intelligence that explains itself.**

> ⚠️ **ALL football data in MatchShift is synthetic.**
> Every club, player, match, event, score, lineup and tactical pattern is fictional and generated by
> MatchShift's own seeded simulator. No live Premier League data, real player statistics, scraped
> websites, paid sports APIs or proprietary feeds are used anywhere.

MatchShift is built for the Microsoft + Premier League **"Inside the Game" Developer Hackathon**. It reads a
stream of football-realistic synthetic events and answers:

- **What happened?** · **What changed?** · **Why does it matter?**
- **What evidence supports that?** · **How should this viewer hear it?** · **What story is emerging?**

## Core principle

**The LLM never calculates match statistics.** Deterministic C# computes every count, window, percentage,
index and detection, and attaches structured evidence. AI only explains, narrates, personalises and
translates *verified* facts, and a Verification agent rejects any claim that does not match the evidence.

## Repository layout

```
MatchShift.sln
src/
  MatchShift.Core            Domain model: events, teams, players, pitch conventions, insight types
  MatchShift.SyntheticData   Seeded simulator, fictional clubs, flagship + labelled scenarios, datasets
  MatchShift.Analytics       Rolling windows, metrics, pressure/control/chaos, shift detection
  MatchShift.Agents          Agent pipeline, narratives, recaps, verification, AI provider abstraction
  MatchShift.Infrastructure  Microsoft Foundry provider, exporters, telemetry wiring
  MatchShift.Api             ASP.NET Core API + live playback engine
  MatchShift.Web             React + TypeScript + Vite broadcast UI
tests/                       xUnit test projects
tools/MatchShift.Cli         Dataset generation / inspection CLI
docs/                        Architecture and design documentation
```

## Quick start

Requirements: .NET SDK 10, Node 20+.

```bash
dotnet build
dotnet test
dotnet run --project tools/MatchShift.Cli -- inspect
```
