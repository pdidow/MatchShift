# Hackathon mapping - "Inside the Game" (Microsoft + Premier League)

> **ALL football data in MatchShift is synthetic.** Fictional clubs, players and matches, generated by a seeded
> simulator. No live Premier League data, real statistics, scraped sites, paid APIs or proprietary feeds.

| Competition goal | How MatchShift delivers it | Evidence in the repo |
|---|---|---|
| **Analyze match events in real time** | Events stream into an incremental `MatchState`; detectors evaluate every match-minute using only past events; SSE pushes snapshots; playback at 1/2/5/10x with seeking that rebuilds analytics exactly | `LiveMatchAnalyzer`, `DemoSession`, `DetectorTests.Live_analysis_never_looks_ahead` |
| **Generate stories, highlights and recaps** | Live narrative cards (ticker, commentator/studio, analyst, fan), ranked highlight timeline, half-time & full-time recaps in casual / analyst / broadcast / social styles | `HighlightRanker`, `RecapBuilder`, `RecapNarrator`, [RECAPS.md](RECAPS.md) |
| **Explain key moments and tactical patterns** | 11 shift detectors + key moments; every insight has structured evidence; **WHY?** evidence panel and **SHOW ME** pitch replay; FACT / INFERENCE / POSSIBLE EXPLANATION separated; intent never claimed | [EXPLAINABILITY.md](EXPLAINABILITY.md), [MATCH_SHIFT_DETECTION.md](MATCH_SHIFT_DETECTION.md) |
| **Expand datasets for AI and analytics** | Seeded simulator, six labelled scenario families with ground truth kept outside the event stream, batch generation, detector evaluation (precision / recall / false alarms), Fabric-ready JSONL/CSV/Parquet export | [SYNTHETIC_DATA.md](SYNTHETIC_DATA.md), `DetectorEvaluator`, `matchshift export` |
| **Deliver multilingual insights** | Semantic insights rendered via English, French and Spanish lexicons with culture-correct numbers; tests prove facts carry identical numbers in every language; Foundry can rephrase under verification | [NARRATIVES.md](NARRATIVES.md), `NarrativeTests` |
| **Deliver personalized studio, streaming and fan experiences** | Teach me football, Just what matters, Tactical analyst, My club / my player, Studio mode; broadcast-style UI with talking points and on-air lines | `ViewerMode`, `NarrativeFilter`, React UI |
| **Use Microsoft technologies meaningfully** | Microsoft Foundry for verified narrative generation (keyless via managed identity); Azure Container Apps + ACR + Application Insights via Bicep / `azd`; Microsoft Fabric as the dataset and evaluation lakehouse; GitHub Actions CI incl. detector evaluation; Copilot guidance | [MICROSOFT_INTEGRATION.md](MICROSOFT_INTEGRATION.md) |

## What makes it different

- **Detection is measured, not asserted.** Labelled synthetic scenarios give precision/recall and negative-control
  false-alarm rates; the thresholds were chosen from sweeps, and the docs report the weak spots honestly.
- **AI can't invent football.** The LLM receives verified facts; the Verification agent checks every number; the
  Event Analyst agent independently recomputes cited metrics from raw events.
- **It always works.** Template narratives in three languages mean judging never depends on a quota or network.

## Responsible use

Synthetic-only data; fictional names; MatchShift metrics are labelled as MatchShift-derived (not official
statistics); explanations are hedged and never attribute intent to (fictional) players or coaches; no secrets in
the repository (`.env.example` only).
